# SAN – AI Fitness & Diet Chatbot 💪

SAN is a command-line fitness chatbot powered by Google's Gemini model. It collects a few basic details about you, calculates key body metrics, and generates a personalized multi-day diet plan based on your goal (muscle gain, weight loss, or weight maintenance). It can also give step-by-step recipes for meals.

Inspired by Chris Bumstead, six-time Mr. Olympia.

---

## Features

- **Personalized diet plans** for a number of days you choose, tailored to Veg or Non-Veg preference
- **Goal-based planning**: muscle gain, weight loss, or maintaining weight
- **Automatic health metrics**:
  - BMI (Body Mass Index)
  - BMR (Basal Metabolic Rate), using the Mifflin-St Jeor or Harris-Benedict equation
  - TDEE (Total Daily Energy Expenditure) across five activity levels
- **Recipe generator**: ask for "recipe for <meal>" and get step-by-step instructions
- **Free-form chat** with the fitness assistant for any other fitness or nutrition question
- **Nutrition lookup helper** using the API Ninjas Nutrition API
- Conversation memory within a session

## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Install dependencies**
   ```bash
   pip install google-generativeai requests
   ```

3. **Add your API keys** (see [API Setup](#api-setup) below)

4. **Run the bot**
   ```bash
   python san.py
   ```
   (Replace `san.py` with the name of the main file in this repo.)

---

## API Setup

The bot needs two API keys:

| Service | Purpose | Get a key |
|---|---|---|
| Google Gemini | Generates diet plans, recipes and chat replies | https://aistudio.google.com/app/apikey |
| API Ninjas | Nutritional info lookup | https://api-ninjas.com/ |

Create a file named `credentials.ini.txt` in the project folder:

```ini
[gemini_ai]
API_KEY = your_gemini_api_key_here

[nutrition_api]
API_KEY = your_api_ninjas_key_here
```

You will also need to update the `genai.configure(api_key="...")` line near the top of the script with your own Gemini key, or change it to read from the config file.

## Usage

1. Start the program and type a request such as:
   ```
   I want a diet plan for muscle gain
   ```
2. Enter the details when prompted:
   - Height (cm)
   - Weight (kg)
   - Age
   - Gender (male/female)
   - Diet preference (Veg / Non Veg)
   - Activity level (1 to 5)
   - Number of days for the plan
3. SAN prints your BMI, BMR and TDEE, then returns a detailed diet plan.
4. Ask for recipes with:
   ```
   recipe for oats protein pancakes
   ```
5. Type `quit` to exit.

### Activity levels

| Level | Description | Multiplier |
|---|---|---|
| 1 | Sedentary | 1.2 |
| 2 | Lightly active | 1.375 |
| 3 | Moderately active | 1.55 |
| 4 | Very active | 1.725 |
| 5 | Super active | 1.9 |
